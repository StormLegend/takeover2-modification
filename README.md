# Takeover 2 简体中文补丁

适用于 **Windows Steam 版，Build 26531378**。汉化菜单、设置、教程、剧情字幕、挑战和结算。保留原版配音；贴图和 Steam 成就页面可能仍显示英文。

**安装：**从 Releases 下载 ZIP 并完整解压。退出游戏，双击 **Install.cmd**，然后从 Steam 启动游戏。原来用其他语言的玩家，可以在设置里切换到「简体中文」（原英语选项）。

**卸载：**退出游戏，双击 **Uninstall.cmd**。Steam 更新可能覆盖补丁。

仓库包含源码和译文。安装器在本机生成补丁并备份原文件，压缩包不含游戏原文件。补丁代码及译文按 [MIT](LICENSE) 许可发布；Mono.Cecil 的许可证见 [vendor](vendor/Mono.Cecil.LICENSE.txt)。非官方补丁。
